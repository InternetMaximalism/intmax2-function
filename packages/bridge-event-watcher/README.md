
# bridge-event-watcher

bridge-event-watcher is a tool designed to monitor and process bridge transactions on blockchain networks, including LayerZero-based bridges. It supports multi-chain event watching and processing for interoperability protocols such as LayerZero, enabling seamless cross-chain asset transfers and monitoring.

## Usage

To set up the development environment:

```bash
# install
yarn

# dev
yarn workspace bridge-event-watcher dev

# build
yarn build
